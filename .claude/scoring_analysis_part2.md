### 4.2 v6的致命错误

#### **错误1：过度简化Overview（违反学生预期）**

**v5版本（正确）：**
```python
OVERVIEW_INTRO_LINE = "This video will be divided into the following parts"
# 输出：5-12项详细章节列表
# 示例："the first part, Basic Concepts"
#       "the second part, Core Principles"
```

**v6版本（错误）：**
```python
OVERVIEW_INTRO_LINE = "Today's roadmap"  # ❌ 过于口语化
# 输出：3-6项"高层学习路径"
# 示例："Start from the core problem"
#       "See why the first idea helps"
```

**为什么这是错误的？**
1. **学生需要具体的章节预期**，而不是抽象的"学习路径"
2. 评测反馈明确指出：学生依赖Overview来预知"what will be covered"
3. "Today's roadmap"过于口语化，缺乏学术感（评测偏好学术化表达）
